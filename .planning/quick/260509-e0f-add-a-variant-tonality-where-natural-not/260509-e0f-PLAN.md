<objective>
Add a `--mode cents-naturals` variant tonality that emits a parallel `.doricolib`
identical to `--mode cents` except that natural ±cents accidentals render as
♮ + cent text (Class B shape applied to base="natural") instead of bare cent
text (Class C). Zero-cent natural stays Class A. Sharp/flat ±cents are
structurally identical to the standard cents library, but their accidental and
composite entityIDs are different (variant-suffixed keys) so the two libraries
coexist in Dorico's picker without entityID collision.

Purpose: Some users want every staff position to carry an explicit accidental
glyph (visual parity with sharp/flat for natural-deviation pitches). Ship as a
sibling library, not a replacement — the existing `cents.doricolib` is locked
(D-05) and must remain byte-identical.

Output:
- New CLI mode `--mode cents-naturals` (default `--out cents-naturals.doricolib`)
- New tonality system display name in Dorico picker: `"cents (naturals shown)"`
- 597 accidentals, same per-section counts as cents mode (1/1/597/1/198/3/597)
- Shared 12-EDO temperament entityID with cents mode (rationale: identical
  divisions, no behavioral diff, halves Dorico's parsing cost on import)
- Variant-suffixed accidental/composite/accidental-system/tonality entityIDs
  so cents.doricolib + cents-naturals.doricolib install side-by-side
- Determinism guarantee: re-running the new mode is byte-identical
- Regression guarantee: re-running `--mode cents` produces byte-identical
  output to the shipped v1.0 `cents.doricolib`

Out of scope (deferred):
- README update documenting the new mode (separate doc task post-merge)
- Visual offset tuning for ♮+cent (uses existing CLASS_B_ATTACH_*; if naturals
  collide with note heads more than sharps/flats, adjust in a follow-up)
</objective>
