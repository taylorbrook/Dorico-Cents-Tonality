The byte snapshot extracts the relevant `<AccidentalDefinition>...</AccidentalDefinition>` block from the emitted body, normalizes every entityID to a literal `<HEX>` token (so the assertion is robust against UUID values), and compares to a pinned multiline string.

Normalization helper (define inline in `tests/test_cents_snapshot.py` — simpler than the per-kind sequential variant in test_template_roundtrip.py):

```python
ENTITY_ID_RE = re.compile(r"([a-z-]+)\.user\.[0-9a-f]{32}")

def _normalize_entity_ids(s: str) -> str:
    """Mask every UUID to '<kind>.user.<HEX>' for byte-faithful snippet diffing.

    Simpler than test_template_roundtrip.py's per-kind sequential index — for
    snippet diffing within a single AccidentalDefinition / CompositeDefinition
    block we just need 'this is some 32-hex UUID' equivalence, not 'first
    occurrence here matches first occurrence there'.
    """
    return ENTITY_ID_RE.sub(r"\1.user.<HEX>", s)
```
